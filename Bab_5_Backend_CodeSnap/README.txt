Folder ini berisi enam potongan implementasi backend untuk kebutuhan Gambar 5.1 sampai Gambar 5.6 pada Bab 5.1.2.

Setiap file merepresentasikan satu gambar CodeSnap. Potongan kode diringkas dari source project agar mudah dibaca dalam laporan. Source code production tidak diubah. Fallback payload compatibility, import panjang, dan detail teknis yang tidak dibahas tidak ditampilkan. Kode lengkap tersedia pada source project dan Lampiran F.
